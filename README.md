# 🚀 SyncSpace

## 📌 Overview

SyncSpace is a real-time collaborative coding platform where multiple users can join the same room, chat, edit code together, and use a shared whiteboard.

---

## ✨ Features

- 👥 Create and Join Rooms
- 💬 Real-time Chat
- 💻 Live Code Editor
- 🎨 Shared Whiteboard
- 👤 Participants List
- ▶️ Run JavaScript Code
- 📋 Copy Room ID
- 🚪 Leave Room

---

## 🛠️ Tech Stack

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Socket.IO
- Monaco Editor
- Axios

---

## ▶️ Installation

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```
